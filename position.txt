Join the Institute for Cyber-Enabled Research (ICER) as a LLM Research and Development Technician! This is an ideal position for a motivated student interested AI development and coding.

Duties primarily include:

Work with ICER staff to develop an AI agent to assist users with submitting their code to run on the HPCC
Manage a software repository and be able to collaborate with others on developing code
Develop testing and validation schema to evaluate the accuracy of agents when given code to evaluate
Gather data on agent performance and present results to ICER staff, leadership, and at MSU research forums
The ideal candidate will have the following:

Experience coding with Python
Comfortable working with command line interfaces
Capable of solving programing problems by making use of reference material, question and answer boards, and LLMs
An interest in studying the outcomes and performance of software and presenting this as research
Self-motivated and able to work independently; also, comfortable receiving feedback and collaborating with others
Desired skills for the role include, but are not limited to, experience in coding languages and willingness, familiarity with MSU's HPCC and SLRUM scheduling system, experience with developing integrated software pipelines, experience working with or training agentic AI, experience with data analysis relating to the validation or testing of AI and machine learning models.
